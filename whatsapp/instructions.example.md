The WhatsApp desktop app connects to this PC, so a new PC doesn't use up another WhatsApp linked device. Never tell the user to link another device to set it up.

If the health tool says WhatsApp isn't linked, the user needs to run C:\mcp\whatsapp\Pair-WhatsApp.cmd on the home PC, then C:\mcp\services\mcpctl.ps1 start whatsapp.
