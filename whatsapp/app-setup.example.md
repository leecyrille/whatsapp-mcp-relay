# WA Relay on a new PC

1. Download the installer from the link above, or from the repo's latest GitHub release.
2. Run it. It needs no admin rights. Windows SmartScreen may warn because the app isn't code-signed: choose More info, then Run anyway.
3. Open WA Relay. Enter your relay address, for example https://d.example.com, and sign in with an allowed email and its emailed PIN.
4. Chats copy to this PC by themselves, usually within a minute. Search works from then on, even offline.

Updates install themselves from GitHub Releases. Settings > Updates turns that off.
